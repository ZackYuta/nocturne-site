プライバシーポリシー

制定日: 2026年11月14日

Nocturne（以下「本アプリ」）は、Mac の Safari で明るい Web サイトを暗い配色に置き換えて表示する機能拡張と、その機能拡張を入れるための Mac アプリです。本アプリの開発者（以下「開発者」）は、利用者の情報を次のとおり取り扱います。

1. 集める情報

開発者は、利用者の個人情報・閲覧履歴・Web ページの内容・利用状況を一切集めません。本アプリには、広告、利用状況の計測（アナリティクス）、外部のサーバーへ情報を送る仕組みは含まれていません。アカウント登録もありません。

2. Web ページの内容へのアクセスについて

Safari は、本アプリの機能拡張について「Web ページの内容を読み取り・変更できる」と表示します。これは、ページの色を置き換えるために必要な権限です。本アプリがこの権限で行うことは、次に限られます。

  • ページのスタイルシート（CSS）と、要素に指定された色を読み取り、暗い配色に置き換えた上書きの指定をページに加えること
  • ページがもともと暗い配色かどうかを、背景色から判断すること
  • サイトごとの設定（自動・常にダーク・オフ）を当てはめるために、表示中のページのホスト名（例: example.com）を参照すること

ページの文章、フォームに入力された内容、パスワード、Cookie などを読み取ったり保存したりすることはありません。

3. CSS ファイルの取得について

ページが別のドメインから読み込んでいる CSS ファイルは、Safari の制限により機能拡張から直接読めないため、本アプリが同じ URL から CSS ファイルを取得し直すことがあります。この取得では Cookie などのログイン情報を送らず、CSS 以外の種類のファイルは使いません。取得先はページがもともと読み込んでいる CSS の配信元だけで、開発者のサーバーを含むほかの場所へは通信しません。

4. 設定の保存

テーマ、時間帯、明るさ、サイトごとの設定（ホスト名と、その設定）は、利用者の Mac の Safari の機能拡張用の保存領域にだけ保存されます。開発者がこれらを見ることはできません。

5. 動くサイトを選ぶ

利用者は、Safari の設定 →「Web サイト」→「Nocturne」で、本アプリが動くサイトを選べます。許可していないサイトでは、本アプリはページを一切読み取りません。手順は使い方をご覧ください。

6. 第三者への提供

開発者は情報を集めないため、第三者へ提供する情報はありません。

7. お子さまの利用

本アプリは年齢を問わず使えます。お子さまの情報を含め、利用者の情報を集めることはありません。

8. このポリシーの変更

内容を変更する場合は、このページで告知します。情報の取り扱いを広げる変更をする場合は、本アプリの更新内容にも記載します。

9. お問い合わせ

このポリシーに関するお問い合わせは、お問い合わせのページをご覧ください。
