# nocturne-site

Mac の Safari 機能拡張「Nocturne」の公開ページ（紹介・使い方・プライバシーポリシー・お問い合わせ）です。GitHub Pages で公開しています。

- トップ: https://zackyuta.github.io/nocturne-site/
- 使い方: https://zackyuta.github.io/nocturne-site/how-to/
- プライバシーポリシー: https://zackyuta.github.io/nocturne-site/privacy/
- お問い合わせ: https://zackyuta.github.io/nocturne-site/support/

このリポジトリの中身は、開発用リポジトリの `site/` フォルダを写したものです。ここを直接編集せず、開発用リポジトリの `site/` を直してから写してください。

## 画像について

- `assets/icon-*.png`・`apple-touch-icon.png`・`favicon-32.png` は、拡張機能のアイコンから書き出したものです。
- `assets/shots/` の画面は、説明用の架空の管理画面に Nocturne を適用して撮ったものです。
